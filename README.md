IFC Model Enrichment for Natural Ventilation – IDS Specification
This repository contains the add-on developed for enriching IFC models with natural ventilation properties based on the AirflowNetwork system.

Requirements
Blender version: 4.3.1
[Bonsai Add-on] for manipulating and validating IFC models

Contents
Addon: [Natural_Ventilation_AddOn] for enriching IFC with AirflowNetwork properties

IFC model: An example IFC file representing a single-family residential building

IDS file: Specification used to validate the enriched IFC model

Installation
Install Blender version 4.3.1

Install the Bonsai add-on and the custom add-on [Natural_Ventilation_AddOn]

Follow the instructions provided in the paper.
